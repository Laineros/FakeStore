# FakeStore

Небольшое React-приложение с роутингом и данными из API `https://fakestoreapi.com/products`.

## Что есть в проекте

- Страница со списком товаров: `/products`
- Страница товара: `/product/:id`
- Страница `404` для неизвестных роутов
- Рейтинг товаров в виде звезд

## Запуск проекта

1. Установить зависимости:

```bash
npm install
```

2. Запустить в режиме разработки:

```bash
npm run dev
```

3. Открыть адрес из терминала (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
```

## Деплой на GitHub Pages

```bash
npm run deploy
```
